# Icon artwork

`icon-glyph.svg` is the `robot-fill` glyph from [Phosphor Icons](https://github.com/phosphor-icons/core),
used under the MIT License. Copyright (c) 2023 Phosphor Icons.

`icon.png`, `icon.ico`, and the tray images in `src/main/tray-icon.ts` are generated from that glyph
by `scripts/generate-icons.mjs`. Run `npm run icons` to regenerate them.
